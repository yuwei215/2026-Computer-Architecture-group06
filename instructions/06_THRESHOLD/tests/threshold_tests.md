# THRESHOLD 測資

依規則 `rs1 >= rs2` 使用有號比較；條件成立時預期輸出為 255，否則為 0。預期輸出依規格手算。

| # | 類型 | rs1 | rs2 | 預期輸出 |
|---|---|---:|---:|---:|
| 1 | 官方：相等 | 5 | 5 | 255 |
| 2 | 官方：差 1 | 4 | 5 | 0 |
| 3 | 官方：負對 0 | -1 | 0 | 0 |
| 4 | 正數大於門檻 | 7 | 3 | 255 |
| 5 | 正數小於門檻 | 3 | 7 | 0 |
| 6 | 兩個都是 0 | 0 | 0 | 255 |
| 7 | 兩個都是負數 | -3 | -5 | 255 |
| 8 | 負數對正數 | -3 | 2 | 0 |
| 9 | 正數對負數 | 2 | -3 | 255 |
| 10 ✱ | rs1 = 最大值 2147483647 | 2147483647 | 2147483646 | 255 |
| 11 ✱ | rs1 = 最小值 -2147483648 | -2147483648 | -2147483647 | 0 |
| 12 ✱ | rs2 = 最小值 -2147483648 | -2147483647 | -2147483648 | 255 |
